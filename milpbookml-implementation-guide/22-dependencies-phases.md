# 22 — Dependencies and Implementation Phases

## Mandatory runtime inventory

GNU/Linux with user namespaces/cgroup v2, rootless Podman plus pinned `podman-compose`, PostgreSQL 18 + pgvector, application images, filesystem blob volume and Bubblewrap are baseline. SearXNG/Playwright are required when research capability is enabled. FFmpeg/TTS/STT/image/video providers are capability dependencies only.

## Phase gates

### Phase 0 — Harness

Repository boundaries, rootless deployment, migrations, accounts/sessions, jobs/outbox, blob protocol, capability profile, requirement ledger and deterministic CI.

### Phase 1 — Source-to-grounded-chat

Notebook/source ownership, text/PDF ingestion, basic Source Guide, canonical provenance, hybrid retrieval, provider gateway, ordinary grounded chat, citations, disclosure and public-boundary E2E.

### Phase 2 — Universal ingestion

Office/image/audio/video/web families, isolated parsers, refresh/versioning, OCR/transcripts, rebuild/purge and broader retrieval evaluation.

### Phase 3 — Research/execution

SearXNG, hardened fetch, Playwright, research state/provenance, Bubblewrap and approval/security tests.

### Phase 4 — Text/data Studio

Notes, document reports, Interactive Learning Overview, tables, mind maps, flashcards and quizzes with revision/export/study state.

### Phase 5 — Visual/document Studio

Slides, infographics and render/export/manual perceptual QA.

### Phase 6 — Audio/video

Audio Overview, optional realtime, Video Overview, asynchronous provider recovery, rights/safety and media runbooks.

### Phase 7 — Collaboration/late parity

Sharing, concurrency, copy/public-link policy and enabled optional/provisional capabilities.

Each phase ships a conformance profile, migrations, SBOM, evidence bundle and zero unclassified normative requirements.
