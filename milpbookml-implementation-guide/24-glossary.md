# 24 — Implementation Glossary

- **Active source version**: immutable version atomically selected for future retrieval.
- **Adapter**: infrastructure implementation of an application port.
- **Capability profile**: machine-readable declaration of implemented/enabled behavior and tests.
- **Canonical document/node**: normalized versioned representation and addressable evidence unit.
- **Content manifest**: immutable exact inputs used by a model/tool/artifact operation.
- **Custody state**: locked ownership-resolution state that grants no content access.
- **Derived restriction**: effective exposure rule inherited from content-bearing ancestors.
- **Evidence record**: immutable fetched/tool-produced item with provenance and trust metadata.
- **External dispatch**: transmission of user/notebook content outside the installation trust boundary.
- **Job lease**: time-bounded exclusive right for a worker to advance a durable job.
- **Outbox**: events committed with domain state and dispatched asynchronously.
- **Parity**: functional behavioral target, not Google ecosystem or pixel identity.
- **Port**: provider-neutral typed interface owned by application/domain layers.
- **Purge**: irreversible traversal and erasure of system-controlled content copies.
- **Rendition**: derived presentation file whose canonical artifact remains structured data.
- **Source locator**: media/type-specific address back to pinned original evidence.
